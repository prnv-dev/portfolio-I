# Pranav Kadam — Portfolio

Personal site of Pranav Kadam. Next.js 14 (App Router), TypeScript, Tailwind and CSS Modules.

## Run

```bash
npm install
npm run dev
```

## Structure

- `app/` — routes, `globals.css` (reset, design tokens, fonts, global utilities), API route for Nova
- `components/<domain>/<Component>/` — each component with its own `.module.css`
- `components/animations/` — Particles, DotGrid, OrbitImages, ShinyText
- `data/` — profile, products, projects, skills, navigation
